# ADR-0004 图片零持久化

- 状态：已采纳
- 日期：2026-11-05

## 背景

冰箱照片包含家庭环境，敏感度高；对象存储还会带来成本、清理和合规负担。

## 决策

- 图片只在设备侧临时文件与内存中存在：`wx.compressImage` → `readFile` → Base64 → 删除临时文件。
- Base64 只作为请求体透传，云函数不落盘（不写 `/tmp`、不写云存储、不写 DB）。
- Supabase 里只有 `observations.items_json` 等结构化结果。

## 后果

- 好处：无图片泄漏面；无存储成本；无需清理任务。
- 代价：无法"重新识别历史照片"，用户要追溯只能看结构化观测；出问题时没有原图可复现（用 `meta` 里的模型/用量排查）。
- 约束：任何新功能都不得引入图片存储；需要缓存时缓存 Base64 于内存且请求结束即释放。

## 何时重新审视

只有在用户明确要求"历史记录带照片"且接受加密对象存储 + 保留策略时，才允许推翻，必须新增 ADR 并更新安全检查清单。
